Dawarich：自架地圖軌跡時間軸，取代 Google Timeline

發表於2026-09-11|更新於2026-09-11|Self Hosting

背景與需求

身為一個記錄控，我過去睜一隻眼閉一隻眼地允許 Google 每天記錄我的 GPS 軌跡，以便我有時間軸歷史記錄供我自己備考。實在是沒辦法，因為就這個需求而言本來沒有太多選擇，只好出賣自己的隱私換取這個服務。

但總算，繼 Immich 好用到足以取代 Google Album 之後，現在 Dawarich 也好用到足以取代 Google Timeline 了——又是開源的勝利！如果你想找一個自架的軌跡時間軸服務，我認為目前 Dawarich 是個可以參考的選項。

記錄方式一樣是用手機作為蒐集 GPS 的設備，但資料直接回傳到自己的 server。也就是說，你可以不用再給 Google 你的位置信息咯。

以我們讀書會去福山植物園考察山羌（超級多山羌！野生的哦，都不怕人）的位置軌跡為例，給大家欣賞一下 Dawarich 的網頁界面，還挺好看的可不是嗎：

手機端的也挺驚艷：

除了瀏覽界面的 UI 設計很不錯之外，它的 Poster Studio 能自訂參數，輸出美麗的軌跡海報：

當然，作為記錄控並不是真的純粹愛記錄，而是蒐集來的 data 可以拿來分析，給自己一些洞見。我自己的看法是，「純記錄不分析」很大程度上就淪於所謂「形式大於內容」，不可不慎。但移動軌跡、日記、相簿這些「記錄本身就包含內容」的資料就還好啦，所以我只是隨口 murmur 一下（？），以後再來談談我過去的一堆「形式大於內容」的折騰。不過 Dawarich 倒是真的有針對資料提供一些 insight，還真就把我的活躍時間給準確地揪了出來：

為什麼活躍時間要在早上呢？請參考《為什麼我九點睡？》

安裝方式

本次服務老樣子用 docker 運行在我的 linux server 中，但有別以往用 Nginx Proxy Manager 反向代理從外網訪問進來，這次我採用 Tailscale 的方案，不過核心概念都是一樣的，不多贅述。至於我對 Tailscale 的評價…… 簡直就是魔法，太方便了，歎為觀止。

調整 docker compose

此處我們採用官方的 docker-compose.yml：

一共會 run 起四個服務。其中我們對 dawarich_app 進行一些修改，建議用 .env 設定環境變數：

  • DAWARICH_APP_PORT=5487 設定服務的 port，此處照慣例設為 5487。
  • APPLICATION_HOST=tailscale-name,100.87.87.87 設定可接受的訪問url。以此處為例，因為 Tailscale 有 Magic DNS，可以填入 server 在 Tailscale 中的裝置名稱 tailscale-name。當然也可以填入 Tailscale 發的 IP 位置，都會是 100 開頭，此處假設 100.87.87.87。如果你不是用 Tailscale，那就是填入反向代理設定的 url。
  • TIME_ZONE=Asia/Taipei 設定你的時區，此處設台北。

運行服務

docker compose up -d 走起，服務啟動。

訪問服務

至此，可以用 tailscale-name:5487 或 100.87.87.87:5487 來進行訪問。

疑難雜症

初次訪問你會發現啊是要怎麼登入，還真是好問題，因為文件也沒有寫清楚這部分。反正後來從 issue 翻到預設的登入帳號密碼為：demo@dawarich.app/safepassword，進去後再修改成自己即可。
